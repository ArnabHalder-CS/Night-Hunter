# Privacy Policy

Last updated: September 22, 2026

Night Hunter does not include advertising, analytics SDKs, or hidden telemetry.

The desktop application stores scan history and reports locally on the user’s device. Security checks run only when a user starts them. A target URL or host entered by a user may be contacted when that selected check requires it; Night Hunter does not send targets to a separate tracking service.

The hosted dashboard is not a substitute for the local scanning engine. Local Nmap results are created on the user’s device and are not uploaded by Night Hunter.

Do not enter passwords, private keys, or confidential targets unless you are authorized to use them. Users are responsible for their own reports, exports, and network-testing authorization.

For privacy questions, open an issue in the official GitHub repository.
